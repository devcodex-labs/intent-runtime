## 仍需验证及建议

1. **独立质量基准。** 冻结完整标签及可接受的歧义处理规则，让目标模型生成、独立评审并人工裁决分歧。补充未见过的真实业务输入和领域；不能把助手自评、重放或受控候选当作生产准确率。
2. **按目标路径重跑。** OpenAI、xAI、Windows/Codex 桌面尚无真实运行；新 Prompt 的完整 119 条需各路径执行。关键否定、确认、撤回、续接、关联和扩展失败每路径至少五次，单列稳定性及修复前错误。API runner 不验证桌面原文交接。
3. **组合与长时运行。** 当前覆盖有限具体组合，未穷尽自然语言。需覆盖跨语言混写、更多领域和日期/单位表达、长上下文里多次纠正/确认交织、持续并发、连接异常、内存/重放预算压力及实际客户端调度。
4. **真实响应及成本基线。** 采集模型请求、修复和总 parse 耗时，按模型、语言、字段规模分组计算 p50/p95，再设目标。当前 120 秒配置上限不等于已验收性能指标，未记录真实 token 成本。

本地 `npm run evaluate -- --all --repeat 5` 可运行全清单并重复请求；`--additional --case X-01 --repeat 5` 可先验证撤回边界。每次阶段记录完整任务、Prompt SHA-256、模型回复及耗时，每条立即落盘；密钥和 HTTP 请求头不记录。冻结动作/状态/data/issues 的比对只覆盖相应维度，整体语义仍 pending。用独立评审计算完整请求通过率、各动作 precision/recall、状态/条件及字段来源正确率；输入拒绝、待裁决样本和重复运行分开列出。
