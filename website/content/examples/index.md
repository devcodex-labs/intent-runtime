# 场景与消费

## 没有选择字段

`parse({input: '分析项目，不修改代码'})` 仍识别目标和 prohibition，inputs 默认空。它不搜索项目、不推导实施步骤或自动执行分析。调用方要理解项目材料，应显式提供相关 JSON Context。

## 多轮与父子目标

第一轮“实现用户模块，包括登录和注册；不得修改数据库；交付说明文档”产生单份父子树和约束。第二轮“注册取消，登录保留，文档改英文”显式传 baseline，保留相关 ID 与限制，只记录本轮变化。第三轮“采用第二种方式”没有选项时保留歧义；回答“邮箱验证码，先不要修改代码”解除相应问题，保留禁止修改代码。

## 字段依赖

只选 discount，也可内部读取显式 isVip，不把 isVip 新写入 inputs。VIP=true/15 合法；改 false 后旧 15 失效；给 5 解除问题。isVip 存在性未知时必须包含不存在世界，不能默认 false。仅属性数量需要 note 的存在时，不必知道 note 的字符串内容。

## 自然语言描述

endTime 描述“必须晚于 startTime”。模型解释材料并给出字段关联判断，真实 Validator 检查格式；已知顺序错误不得进入 inputs。缺开始时间时保留 unknown/问题，不查询外部数据。更正后问题可解除，其他合法参数保留。

## 应用消费

保留原始消息和最终结果，按所属 intentId 和 fieldResults 读取业务参数；展示 unresolved 的澄清。应用自己决定业务工具、授权和执行。并发请求用应用 revision 防止旧结果覆盖新结果。

可运行的 `.mjs` 接入示例位于仓库 examples，使用当前安装包导出；真实模型验收脚本需要环境凭据和外部输出路径。
